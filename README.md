A one-line out-of-office reply for the make.fun bounty: "I'm away until Monday — please direct urgent matters to my office plant; it's been promoted twice and still hasn't replied to anyone." The sender is out, the plant is in charge, and somehow the plant keeps getting promoted.

## Run it

```sh
python3 main.py
```

It writes the line to /output/entry.txt (or MAKEFUN_OUTPUT_DIR) with no trailing newline.
